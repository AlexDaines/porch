# Plural is the visual reference

The user rejected the initial prototype's visual noise, unnecessary text and clunky navigation, and identified Plural as the closer reference. Plural's source and rendered view supplied the black canvas, bone text, thin rules, compact controls and details hidden until requested.

Subsequent direction removed the lime accent and made the interface still quieter, following Light Phone's restraint. Feed, Stories and Messages now share one compact text control row, and all three render live content natively. Settings contains the secondary tools and an initially collapsed About disclosure. Preserve these decisions instead of inferring a new aesthetic from a general house style.
